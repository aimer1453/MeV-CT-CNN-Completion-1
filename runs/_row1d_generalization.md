## 判读

- C 组 Row 16 相对 A 组：**-15.28%**
- C 组 Row 15 相对自身 Row 16：**+18.03%**（镜像行，物理条件几乎相同）
- C 组 Row 0 相对自身 Row 16：**+2134.77%**
- C 组 Row 31 相对自身 Row 16：**+2028.90%**

Row15 是 Row16 的物理镜像行（empty_proj 行均值 22.567 vs 22.493，A 组两行 RMSE 差 0.03%），故 C 在 Row15 上若不显著退化，说明 1D 网络学到的是可迁移的角度插值映射；Row0/31 是低通量边缘行（通量低约 63 倍），退化幅度反映跨物理条件的迁移代价。
